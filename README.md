## Installation

Clone the repository:

```bash
git clone https://github.com/Tehreemirfan123/Portfolio-Website.git
```

Navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm start
```

Create production build:

```bash
npm run build
```
